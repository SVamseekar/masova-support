# Equipment Troubleshooting

## Oven not reaching set point

If a deck oven lags more than 25°F after 20 minutes, check the door gasket, then call facilities. Do not extend cook times as a workaround for more than one ticket.

## Cooler alarm or warm case

Silence only after recording the temperature. If the cooler temperature range is above 41°F, follow HACCP discard rules. Check condenser coils for dust before paging HVAC.

## POS terminal freeze

Reboot the terminal, then the receipt printer. If card payments fail, switch the lane to offline auth only with manager PIN.

## Dish machine temperature

Wash 150°F, rinse 180°F. If rinse is low, stop the machine and use the three-compartment sink until a tech clears it.
