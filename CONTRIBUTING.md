# Contributing

This is a solo-maintained repository. External contributions are not expected;
the documents below exist so a competent engineer can set up, test, and change
the service safely.

- Setup, coding standards, and PR steps: [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md)
- Branching, CI, and commit style: [docs/GIT_WORKFLOW.md](docs/GIT_WORKFLOW.md)
- Releases: [docs/RELEASING.md](docs/RELEASING.md)
- Security reports: [SECURITY.md](SECURITY.md)

Do not add `Co-Authored-By` trailers for AI tools. Do not commit `.env`,
`AGENTS.md`, `CLAUDE.md`, or other local-only files.
